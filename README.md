Manzanas


Descripción

Manzanas es un videojuego sencillo donde el jugador controla una canasta para atrapar las manzanas que van cayendo del árbol. Hay manzanas rojas y verdes, y dependiendo de cuáles se atrapen o se dejen caer se puede ganar o perder la partida.

Herramientas utilizadas

El juego fue realizado utilizando Haxe y el motor OpenFL.

Versiones utilizadas:

Haxe 4.3.7
OpenFL 9.5.2
Lime 8.3.2
Cómo ejecutar el proyecto

Para ejecutar el juego es necesario tener instalado Haxe junto con OpenFL y Lime.

Una vez descargado el proyecto, se debe abrir una terminal dentro de la carpeta del proyecto y ejecutar:

lime test windows

Con esto se compila y se abre el juego en Windows.

Controles

Flecha izquierda: mover la canasta hacia la izquierda.

Flecha derecha: mover la canasta hacia la derecha.

ESC: pausar el juego.

R: volver a jugar después de terminar una partida.

Objetivo del juego

El objetivo principal es atrapar 50 manzanas rojas.

Hay que evitar las manzanas verdes y también evitar que se caigan las manzanas rojas. El jugador pierde cuando atrapa 3 manzanas verdes o cuando se caen 3 manzanas rojas.

Funcionalidades para probar

Se puede probar el movimiento de la canasta con las flechas izquierda y derecha, la aparición de las diferentes manzanas y la detección de cuando una manzana entra en la canasta.

También se pueden probar los contadores de manzanas atrapadas y perdidas, la condición para ganar con 50 manzanas rojas, las condiciones para perder, la pausa con ESC y el reinicio de la partida con R.
